# Velocity Forze — Final Website

## Open locally
Extract the folder and double-click `index.html`.

No terminal or Termux command is required.

## Included
- Single-page Velocity Forze website
- Opening logo transition and section scrolling
- About, Us, Problem, Testimonial and Contact sections
- Interactive Google Maps location for Fattora Foods
- Problem/contact forms with on-page confirmation
- Client testimonial cards
- Carmina's Curry case-study page (`carminas-curry.html`)
- Client logos: Carmina's Curry, Sweet Mamma, Ninth Bar Coffee, Origin Food Ventures
- Responsive layout for mobile, tablet, laptop, desktop and TV-sized screens

## Notes
- Google Maps requires an internet connection when the site is opened locally or published.
- Problem and Contact submissions are stored locally in the visitor's browser and shown an on-page confirmation. A shared server-side inbox/database is not connected yet.
- Carmina's Curry case study links to `https://carminascurry.com`.
