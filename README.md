# Velocity Forze — Release Candidate

Single-page Velocity Forze website.

## Run locally

```cmd
npx serve .
```

Open `http://localhost:3000/`.

## Sections

- Home — logo door / scroll entrance
- About — company information
- Us — team portraits, roles, descriptions and email links
- Problem — cinematic HoReCa video + problem input
- Contact — name, problem and message form

## Theme

White / black / Velocity blue, with the supplied blue logo preserved.
